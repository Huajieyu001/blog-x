## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Browser -> Web | alternate-origin or client fetch bypass | record requests and require one generated Web origin |
| Web -> fixture | malformed/untrusted payload | server-only adapter and strict shared schema |
| Input -> rendered text | injection or hidden-field disclosure | native bounds and escaped strict public projection |
| Runner -> children | stale/broad process cleanup | generated ports, bounded waits and exact handles |
