| Policy → route/repository | Only an accept/ignore decision and fixed source enum may cross. |
| Test filesystem → canonical gate | Every discovered test must have one exact execution owner. |

| T-11-07 | Information Disclosure | header and socket processing | high | mitigate | Pure policy emits only fixed enum/ignore, route logging is disabled, and tests reject any raw value crossing writer/audit/diagnostic seams. |
