<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → same-origin Web/API | Untrusted path, Origin, body and headers enter an anonymous state-changing route. |
| API → PostgreSQL | Validated source and slug cross into a durable aggregate without visitor identity. |
| Migration source → disposable database | Committed schema authority is applied under the existing advisory lock. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-11-01 | Information Disclosure | `POST /public/articles/:slug/view` | high | mitigate | Return exactly empty 204/no-store for public, hidden, invalid and failure outcomes and reuse `publicPredicate` inside the write statement. |
| T-11-02 | Tampering | `recordPublicView` counter update | high | mitigate | One PostgreSQL upsert increments total and one fixed bucket under composite uniqueness and equality/nonnegative checks. |
| T-11-03 | Information Disclosure | `article_daily_views` schema | high | mitigate | Persist only article UUID, Shanghai date and six counters; schema and tests reject all identity/header/event fields. |
| T-11-04 | Denial of Service | anonymous POST | high | mitigate | Enforce exact Origin, 256-byte body limit, strict schemas and later dedicated bounded ephemeral policy without changing the opaque response. |
| T-11-05 | Tampering | migration application | high | mitigate | Generated committed SQL, snapshot and journal are verified through isolated fresh/concurrent/repeated migration plus exact schema inventory. |
</threat_model>
