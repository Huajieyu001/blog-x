## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Administrator browser/SSR -> Fastify | A session cookie and untrusted query cross into protected analytics. |
| Fastify -> PostgreSQL aggregate store | A bounded range/limit becomes a read-only aggregate query over retained rows. |
| Article lifecycle -> analytics projection | Current visibility changes whether already-stored aggregate rows may appear. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
