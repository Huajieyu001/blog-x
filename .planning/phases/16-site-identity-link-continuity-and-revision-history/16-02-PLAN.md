# Phase 16 Plan 02: Public Slug Continuity Audit

<objective>
Close LINK-01’s remaining browser-boundary gap by proving existing durable slug aliases are translated once into safe public page redirects without exposing private lifecycle state or accepting forged upstream locations.
</objective>

<tasks>
<task type="tracer" tdd="true">
  <name>Task 1: Test direct persisted alias resolution across lifecycle states</name>
  <files>apps/api/src/content/admin-repository.ts, apps/api/src/content/article-service.ts, apps/api/src/content/public-repository.ts, apps/api/src/routes/public-posts.ts, apps/api/test/article-slug-redirects.test.ts</files>
  <read_first>apps/api/src/content/admin-repository.ts; apps/api/src/content/article-service.ts; apps/api/src/content/public-repository.ts; apps/api/src/routes/public-posts.ts; apps/api/test/article-slug-redirects.test.ts; apps/api/src/db/schema.ts</read_first>
  <action>Write focused lifecycle regressions for multiple published slug changes, returning to an owned historical slug, collision attempts, concurrent edits, unpublish/delete/schedule/restore, and a tampered/foreign alias target. Assert only root-relative current-slug 308 locations are emitted and aliases never redirect to aliases. Preserve permanent slug reservation and existing transaction/audit contracts. If the existing direct resolution fails a real edge case, correct the repository/service/query path without relaxing public 404 parity; do not create or alter schema/migrations unless a genuine schema defect requires a new repository migration/apply/schema-verify task.</action>
  <acceptance_criteria>
    - Alias lookup is published-only and always resolves to the article’s current slug in one hop.
    - Unknown/private/invalid input yields the same content-free unavailable response, not redirect topology information.
    - No redirect loop, absolute URL, query, traversal, history reuse or cross-article alias transfer is possible.
  </acceptance_criteria>
  <verify>corepack pnpm --filter @blog-x/api test -- article-slug-redirects.test.ts article-lifecycle.test.ts; corepack pnpm --filter @blog-x/api typecheck</verify>
  <done>LINK-01’s persisted API authority is proven against both normal and hostile lifecycle transitions.</done>
</task>
