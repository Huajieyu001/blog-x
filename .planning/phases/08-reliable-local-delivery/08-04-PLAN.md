## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Git SHA -> receipt/claim path | traversal, short/mixed-case or caller-chosen authority | exact lowercase full-SHA validator and pure fixed-root derivation |
| claim -> runtime writer | revision/authority substitution | recompute the expected authority from claim revision at attachment and publication |
| receipt path -> independent verifier | arbitrary file or filename/receipt mismatch | strict repository-relative grammar plus filename, schema, claim, image and runtime SHA equality |
| later Git HEAD -> delivered revision | source/config drift hidden as documentation | ancestry plus finite exact closeout-path allowlist and committed lock equality |
| failed cutover -> receipt cleanup | cleanup fault blocks rollback | immutable API/Web rollback completes before evidence cleanup is evaluated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-04-01 | Spoofing | revision/path/claim identity | high | mitigate | `deliveryAuthorityForRevision` and strict path parser recompute one authority from one full SHA at every boundary. |
| T-08-04-02 | Tampering | historical/current receipts | high | mitigate | Exclusive link publication, existing-final refusal, historical digest regression and first-receipt byte preservation. |
| T-08-04-03 | Repudiation | repeat/concurrent delivery | high | mitigate | One terminal revision claim and bound failure report remain non-overwriting per SHA. |
| T-08-04-04 | Information Disclosure | authority/output | medium | mitigate | Receipt and output retain sanitized digests/counts/fixed paths only; no raw generated authority or secrets. |
| T-08-04-05 | Denial of Service | consumed or malformed SHA authority | medium | accept | The affected SHA fails closed and requires a corrected clean commit; no alternate port/path or same-SHA bypass exists. |
| T-08-04-06 | Elevation of Privilege | path/CLI injection | high | mitigate | Fixed roots, exact one-option diagnostic grammar and zero-argument formal path prohibit arbitrary filesystem, command or server authority. |
</threat_model>
