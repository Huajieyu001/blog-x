| Boundary | Sensitive flow |
|---|---|
| Compose/runtime → status reporter | Raw inspect/stats/log/environment data must become a redacted minimal status. |
| PostgreSQL/export/media/config → staging | Sensitive complete recovery authorities cross into restrictive backup storage. |
| Staging → final backup set | Completeness and checksums determine whether atomic publication is allowed. |
| Backup set → empty restore target | Untrusted/tampered files must be fully validated before mutation. |
| Restored API/Web → browser | Restored content/media remain same-origin and lifecycle-confidential. |
| Runner → cleanup | Generated namespaces, volumes, databases, and roots are the only removable targets. |
