## Trust Boundaries

| Boundary | Sensitive flow |
|---|---|
| Untrusted HTTP client → Fastify | Credentials, cookie, Origin, address authority, JSON/form/multipart bodies, and request volume. |
| Fastify composition → runtime resources | Environment values decide database, filesystem, listener, cookie, and limiter behavior. |
| Routes → service/repository/storage | Rejected calls must never mutate PostgreSQL or media files. |
| Web/config artifacts → topology | Public output and tracked policy must not expose internal/node authority or secrets. |
| Runner → generated services | Generated credentials, database, namespace, logs, and cleanup remain local and exact. |
