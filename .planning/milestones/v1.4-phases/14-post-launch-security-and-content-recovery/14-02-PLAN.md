## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → password API | current/new password 是高度敏感输入，只能经已认证 exact same-origin JSON mutation 进入 API。 |
| API memory → PostgreSQL | 明文只用于 Argon2 verify/hash；持久化仅 replacement hash，session revoke 与 audit 必须同 transaction。 |
| Contract/Drizzle schema → PostgreSQL migration | `auth.password.changed` 必须在 TypeScript authority、SQL checks、snapshot/journal 与 schema verifier 中保持同义且完整。 |
| Audit/log/response → administrator | 可观测诊断只能以独立事件和 allowlisted 字段名说明发生轮换，不能包含密码值、hash、cookie、token 或请求 body。 |
| Shared browser fixture → later tests | 浏览器改密会改变测试 credential，必须在同一用例的 `finally` 恢复。 |
