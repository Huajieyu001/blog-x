<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Administrator browser → deleted APIs | 删除内容 metadata 与 restore mutation 只能越过已认证 same-origin 边界。 |
| Deleted PostgreSQL row → public projections | 恢复必须从 deleted 直接原子进入 draft，不能产生 published+retained 中间状态。 |
| Restore transaction → audit log | 状态更新和 audit evidence 同成同败，audit 不得复制内容。 |
| Deleted row → Slug namespace | 原 row 持续占用唯一 Slug；恢复不能复制、删除或改写该标识。 |

## STRIDE Threat Register (ASVS L1; high blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-03-01 | Information Disclosure | GET /admin/deleted-posts | critical | mitigate | authenticate before query；minimal strict projection/contract；malformed content-bearing responses fail closed；public 404 parity test。 |
| T-14-03-02 | Elevation of Privilege | POST restore | high | mitigate | session-first exact-Origin mutation guard、strict `{}` body、bounded limiter、unsafe route inventory。 |
| T-14-03-03 | Tampering | deleted→draft transition | critical | mitigate | `FOR UPDATE` + one transaction UPDATE to draft/deletedAt-null/schedule-null，forced-audit rollback 与 concurrency tests。 |
| T-14-03-04 | Tampering | Slug reservation | high | mitigate | 只更新原 row 的 lifecycle columns，不 insert/delete/change slug；deleted/restored duplicate conflict assertions。 |
| T-14-03-05 | Repudiation | restore audit | medium | mitigate | transaction-scoped `article.updated` with actor/target and fixed deleted→draft metadata；audit UI 显式标注恢复。 |
| T-14-03-SC | Tampering | package supply chain | high | mitigate | 不安装依赖、不改 manifest/lockfile；出现 package drift 即停止。 |
</threat_model>
