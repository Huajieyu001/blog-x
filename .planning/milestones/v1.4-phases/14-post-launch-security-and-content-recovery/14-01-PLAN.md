<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Next response | 公开或管理员浏览器接收服务端控制的文档、脚本、样式、媒体和 API 响应策略。 |
| Public request → API/media rewrites | 不可信公网请求继续通过 Web 同源入口进入现有可信 ingress，不允许 CSP/headers 改写该边界。 |
| Clean Git SHA → fixed preview | 仅干净 `dev` 修订可获得一次固定本地 refresh claim，receipt 不是生产授权。 |

## STRIDE Threat Register (ASVS L1; high blocks)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01-01 | Tampering | CSP resource policy | high | mitigate | 生产使用显式 self/none directives、禁止 wildcard/eval，并以真实构建和浏览器 console smoke 验证。 |
| T-14-01-02 | Information Disclosure | Referrer/framework headers | medium | mitigate | 使用 strict-origin-when-cross-origin 并关闭 `poweredByHeader`。 |
| T-14-01-03 | Elevation of Privilege | frame embedding | high | mitigate | 同时设置 `frame-ancestors 'none'` 与 `X-Frame-Options: DENY`。 |
| T-14-01-04 | Spoofing | HTTPS downgrade | high | mitigate | 正式 Next 响应发送一年 HSTS；不在本阶段改变 TLS/服务器配置。 |
| T-14-01-05 | Denial of Service | over-restrictive CSP | high | mitigate | 为现有 inline theme/style、same-origin API/media 和 dev HMR 建立环境区分，并跑 build/browser smoke。 |
| T-14-01-SC | Tampering | package supply chain | high | mitigate | 本计划不安装依赖、不改 manifest/lockfile；若出现依赖漂移立即停止。 |
</threat_model>
