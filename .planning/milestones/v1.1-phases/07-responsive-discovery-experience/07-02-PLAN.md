## Trust Boundaries

| Boundary | Risk | Control |
|---|---|---|
| Raw URL -> Proxy marker | malformed or spoofed encoding state | recompute and overwrite on `/search` |
| Decoded params -> contract | duplicate/unknown/bounds bypass | parse complete object once |
| API response -> outcome | malformed/hidden data | strict schema and exhaustive failure |
| Outcome -> body/metadata | disagreement or poisoned canonical | shared memoized authority and PUBLIC_ORIGIN |
