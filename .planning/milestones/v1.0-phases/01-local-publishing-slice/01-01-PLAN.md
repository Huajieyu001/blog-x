## Trust Boundaries

| Boundary | Risk |
|---|---|
| npm registry → workspace | Supply-chain tampering |
| browser → relative `/api` → Fastify | Credential/input spoofing and unauthorized writes |
| Fastify → PostgreSQL | Durable tampering and migration races |
| Markdown → sanitized HTML | Stored browser execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-SC | Tampering | dependency install | high | mitigate | Blocking Task 1 plus exact lockfile. |
| T-01-01 | Spoofing | session | high | mitigate | Argon2id, CSPRNG opaque ID, digest lookup, expiry/revocation, secure cookie flags. |
| T-01-02 | Elevation of privilege | publish route | high | mitigate | Fastify authorization before lookup/mutation and invalid-session tests. |
| T-01-03 | Tampering | migration | high | mitigate | Generated reviewed SQL, advisory lock, schema verification before DB tests. |
| T-01-04 | Tampering | Markdown | high | mitigate | Raw HTML disabled, bounded transform, final sanitizer, hostile fixture. |
| T-01-05 | Information disclosure | secrets/logs | high | mitigate | Environment-only secrets and redaction of password/cookies/tokens/DB URL. |
| T-01-06 | Tampering | cookie write | medium | mitigate | SameSite plus trusted-Origin validation. |
