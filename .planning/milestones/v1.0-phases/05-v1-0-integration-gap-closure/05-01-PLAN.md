As a visitor, I want every published image to load only through the blog origin, so that reading cannot silently contact third-party or mixed-content media hosts while ordinary external links still work.

Purpose: Close audit gap G1, INT-01, and FLOW-07 with one exact media authority plus an explicit, lossless legacy-data disposition.
Output: Shared media policy, defensive renderer and authoring enforcement, generated Drizzle migration and idempotent classifier, admin repair state, CSP defense, API/export/restore tests, browser request proof, and the named known-bad fixture.
</objective>
