<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to admin API | Untrusted schedule/time input crosses session, Origin, rate, and parser controls. |
| API to retained row | State and time decisions become article plus audit mutations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-04 | Spoofing | Schedule routes | high | mitigate | Session-first `requireAdministratorMutation` on every route in Task 1. |
| T-10-05 | Tampering | Cross-origin/time/state input | high | mitigate | Exact Origin, strict form/ISO parsing, database time, and row-locked state checks in Task 1. |
| T-10-06 | Repudiation | Schedule lifecycle | medium | mitigate | One attributed audit event in the same transaction for each successful operation. |
| T-10-07 | Denial of service | Admin mutations | medium | mitigate | Existing bounded administrator limiter and explicit body limits in the unsafe inventory. |
| T-10-08 | Information disclosure | Error/UI output | medium | mitigate | Stable opaque errors and content-free audit rendering proved by API/browser tests. |
</threat_model>
