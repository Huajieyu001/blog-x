## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → authenticated Next administrator layout | Untrusted route/hash/keyboard input enters a client shell only after server-side session authorization. |
| Browser → same-origin management forms/API rewrites | Administrator input and lifecycle mutations must retain existing authentication, Origin/CSRF, request-shape and confirmation boundaries. |
| Local Git revision → fixed refresh authority | Only a clean committed `dev` SHA may claim one local refresh; the receipt is not production authority. |
