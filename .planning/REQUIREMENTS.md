# Requirements: Blog X v1.3 Private Insights

**Defined:** 2026-09-05
**Core Value:** 博主能够可靠地发布和保存 Markdown 内容，访客能够持续、快速地通过博客域名阅读已发布文章。

## v1.3 Requirements

### Privacy-safe Analytics

- [ ] **STAT-01**: 访客每次实际打开已发布文章时，页面可通过同源匿名请求记录一次浏览；未知、草稿、已下线、已删除和尚未到期的文章不计数，且响应不得暴露文章状态。
- [ ] **STAT-02**: 系统只持久化按文章、`Asia/Shanghai` 自然日和粗粒度来源类别汇总的计数，不保存原始访问事件、IP、原始 User-Agent、Referrer URL、Cookie、会话、指纹或持久访客标识，也不生成或声称独立访客数。
- [ ] **STAT-03**: 并发浏览通过数据库原子聚合保持总数与来源分项一致；预加载和可识别爬虫请求在不持久化检查输入的前提下被忽略，匿名写入在滥用或过载时保持有界并失败关闭。
- [ ] **STAT-04**: 每日明细采用 400 天滚动保留期，并由可重复、有界的本地清理命令删除过期聚合，不引入队列、常驻统计服务或第三方分析平台。
- [ ] **STAT-05**: 管理员可在受认证保护且不缓存的后台查看 7、30、90 或 400 天的总浏览量、每日趋势、热门文章和粗粒度来源分布，所有数字明确标注为匿名 PV 趋势而非独立访客或计费依据。
- [ ] **STAT-06**: 聚合统计随完整数据库备份完成逐行等价恢复验证，而既有 Markdown 便携导出保持向后兼容并明确不包含访问统计或访客数据。

### Responsive Admin Workspace

- [ ] **ADMN-01**: 管理员在文章、统计、新建、分类标签、关于和审计页面之间使用统一后台壳层导航，当前页语义、退出入口、移动端开合、Escape 关闭和焦点行为均清晰可用。
- [ ] **ADMN-02**: 后台首页以分组卡片呈现内容工作概况、主要创作入口和访问趋势摘要，不再将所有操作平铺为同等权重的链接。
- [ ] **ADMN-03**: 文章列表以紧凑且可扫描的摘要展示标题、状态、时间和详情入口，危险或低频生命周期操作渐进展开并继续保留确认、预约和无脚本提交语义。
- [ ] **ADMN-04**: 分类标签、关于、审计和统计页面共享一致的标题层级、表单、按钮、卡片、空状态、加载状态和失败状态，同时保留既有脱敏与编辑恢复行为。
- [ ] **ADMN-05**: 后台在 390、768 和 1280 像素宽度下无横向溢出，主要触控目标不小于 44 像素，键盘焦点可见，并完整支持浅色、深色和跟随系统主题。

### Local Delivery Confidence

- [ ] **QUAL-01**: 新统计链路和后台刷新通过契约、数据库并发、安全、备份恢复和同源浏览器自动化验证，且不会回归登录、编辑、预约、发布、软删除、审计、公开阅读和隐私边界。
- [ ] **QUAL-02**: 每个完成的大步骤都将当前 `dev` 源码更新到固定 `http://127.0.0.1:3100` 本地展示环境并执行健康检查；所有收据继续明确生产发布为 `BLOCKED`。

## Acceptance Constraints

- 所有开发、数据库、浏览器和交付验证均在本地完成，不连接、访问或操作任何云服务器，不使用服务器凭据。
- 不修改 `main`，每个完整任务在 `dev` 上原子提交并推送到 `origin/dev`，不执行破坏性命令。
- 统计只表示尽力而为的页面浏览趋势；无访客标识意味着不提供可靠去重、精准反作弊、画像、地域或跨设备归因。
- 匿名统计 POST 使用独立的严格请求策略、同源边界、小请求体、无凭据客户端调用、`no-store` 响应和有界资源保护，不复用管理员 CSRF 语义。
- 管理员统计查询的日期范围、热门文章数量和返回行数必须有严格上限，低配置环境不得引入重型图表库或常驻高内存组件。
- 访问统计不写入管理员 `audit_events`，不改变严格公开文章投影，也不让未公开内容成为可探测对象。
- 主观美观 UAT 记录为里程碑末尾的人工检查项并暂缓，不阻塞其余可自动验证的实现和交付工作。

## Future Requirements

- 自定义日期范围、数据对比、CSV 统计导出和更细来源规则可在真实使用数据证明价值后评估。
- 生产调度器激活、跨节点安全网络、TLS 和主服务器发布继续受生产冻结限制。

## Out of Scope

| Feature | Reason |
|---------|--------|
| 独立访客、访客画像、地域、设备与跨站追踪 | 需要持久访客标识或第三方数据，违背本里程碑隐私边界 |
| 精准反作弊或计费级统计 | 无原始事件和访客标识时不能可靠证明，博客场景也不需要 |
| Google Analytics、Umami、Matomo 等第三方/独立统计服务 | 增加外部数据披露、部署资源和运维复杂度 |
| 实时在线人数与流式事件管道 | 两台低配服务器的使用规模不值得引入常驻组件 |
| 重型后台组件库或图表框架 | 现有 CSS Modules 与轻量语义组件足以满足可视化需求 |
| 任何生产连接或部署 | 用户明确禁止服务器操作，生产仍处于冻结状态 |
